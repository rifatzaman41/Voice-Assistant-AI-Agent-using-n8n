# Voice-Assistant-using-n8n

# Project Overview

This project is an AI-powered company appointment booking system that uses a Vapi Voice AI Agent to interact with users through voice conversations. The AI agent collects essential appointment information, such as the user's name, phone number, company name, and preferred schedule.

After collecting the information, the appointment details are stored in Google Sheets, where they can be easily viewed and managed.

# Features

AI Voice Interaction: Uses Vapi Voice AI to communicate with users naturally.

Automated Information Collection: Collects the following details:

1. Name

2. Phone Number

3. Company Name

4. Appointment Schedule

Google Sheets Integration: Automatically stores collected appointment information in Google Sheets.

Appointment Management: Allows users to view submitted appointment details in one centralized spreadsheet.

# Technology Stack

Vapi AI: Voice-based AI agent

# Project Goal

The main goal of this project is to simplify company appointment scheduling through voice-based AI automation, reduce manual data entry, and organize appointment information efficiently using Google Sheets.

Google Sheets: Appointment data storage

AI Voice Agent: Automated appointment information collection
